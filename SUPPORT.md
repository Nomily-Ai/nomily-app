# Support

## Start here

| Need | Best path |
| --- | --- |
| Product overview, BYOK setup, or fixed-data preview | [Geekis.com](https://geekis.com) and the [online demo](https://geekis.com/demo/) |
| iPhone or Apple Watch build and runtime problem | [nomily-ios issues](https://github.com/Nomily-Ai/nomily-ios/issues) |
| Android build and runtime problem | [nomily-android issues](https://github.com/Nomily-Ai/nomily-android/issues) |
| Public documentation, site preview, or project-entry feedback | [nomily-app issues](https://github.com/Nomily-Ai/nomily-app/issues) |
| General support or commercial licensing | [nomily@geekis.com](mailto:nomily@geekis.com) |
| Security vulnerability | [SECURITY.md](SECURITY.md) |

## Before contacting us

Use synthetic or redacted information. Do not send API keys, recordings,
transcripts, device identifiers, account information, private endpoints,
firmware, or production logs in public issues or email.

Nomily is a BYOK client workflow. Provider credentials, usage charges,
availability, and service behavior remain with the account and provider you
choose. For current public capability boundaries, read the project
[README](README.md).
