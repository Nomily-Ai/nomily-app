# Contributing to Nomily

Thank you for helping improve Nomily. This repository is the public project
entry point: it contains cross-project documentation, licence information, and
preview assets. The runnable clients live in separate repositories.

## Choose the right repository

| Your change or report | Where to start |
| --- | --- |
| iPhone or Apple Watch client | [nomily-ios](https://github.com/Nomily-Ai/nomily-ios) |
| Android client | [nomily-android](https://github.com/Nomily-Ai/nomily-android) |
| Project overview, public documentation, or preview assets | This repository |
| General product question | Read [SUPPORT.md](SUPPORT.md) |

## Before opening an issue

1. Search existing issues first.
2. Use synthetic or redacted reproduction data only.
3. Never include API keys, recordings, transcripts, device identifiers,
   private endpoints, production logs, firmware, or vendor documents.
4. Report vulnerabilities privately using the process in [SECURITY.md](SECURITY.md),
   not in a public issue.

## Pull requests

- Keep each pull request focused on one small, reviewable change.
- Explain the problem, the smallest solution, and how you verified it.
- Update the relevant English, Simplified Chinese, and Traditional Chinese
  documentation when public behavior changes.
- Do not add credentials, binaries, private material, generated build output,
  or unlicensed third-party assets.
- Contributions are submitted under the [Nomily Small Team License](LICENSE).

Nomily maintainers may request clarification, a narrower scope, or a different
repository before reviewing a contribution.
